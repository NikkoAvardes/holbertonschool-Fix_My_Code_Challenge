# Fix My Code – Détails des challenges

Ce dossier regroupe plusieurs petits programmes (Python, JS, Ruby, C) contenant des bugs à identifier et corriger.

## Fichiers racine

- 0-fizzbuzz.py – implémentation à corriger du classique FizzBuzz en Python.
- 1-print_square.js – script Node.js qui affiche un carré de taille donnée.
- 2-sort.rb – script Ruby qui trie une liste en respectant l’ordre attendu.
- 3-user.py – classe User en Python avec gestion d’attributs / identifiant.

## Dossier 4-delete_dnodeint

- add_dnodeint_end.c – ajoute un nœud en fin de liste doublement chaînée.
- delete_dnodeint_at_index.c – supprime un nœud à un index donné.
- free_dlistint.c – libère toute la liste.
- print_dlistint.c – affiche le contenu de la liste.
- lists.h – définitions de la structure de liste et des prototypes.
- main.c – programme de test pour les fonctions de liste.
- delete_dnodeint – binaire de test compilé (non à modifier).

Chaque fichier contient une implémentation à analyser et corriger sans changer l’API publique.
